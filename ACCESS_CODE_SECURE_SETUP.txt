PREVIOUS YEAR PAPERS - SECURE ACCESS CODE

This version keeps the Previous Year Papers table and PDF bucket private.
Students must enter the Access Code before the paper list is returned.
PDFs are opened only through a 5-minute signed URL generated by the Supabase Edge Function.

SETUP:
1. Upload this website ZIP to Netlify only after the Supabase SQL is run.
2. In Supabase SQL Editor, run the FULL setup.sql once.
3. Log in as the admin in the website.
4. Open Admin Panel -> Previous Year Papers Access Code.
5. Enter your own code and press Save Access Code.
6. Deploy the included Edge Function folder:
   supabase/functions/get-previous-year-paper/index.ts
   using Supabase CLI:
   supabase functions deploy get-previous-year-paper
   The normal Supabase project environment provides SUPABASE_URL and
   SUPABASE_SERVICE_ROLE_KEY to the deployed function.
7. Only then upload Previous Year Paper PDFs from Admin Panel.

IMPORTANT:
- Do NOT make the previous-year-papers bucket public.
- Do NOT put the Access Code in index.html.
- Direct public PDF URLs will not work because the bucket is private.
- The signed PDF link expires after 5 minutes.
